# LocalChat Web 服务（多用户）

**Node.js 多用户聊天服务器 + 浏览器界面**：一台服务器（家里主机 / NAS / VPS）
承载多个账号，所有用户从浏览器登录，聊天消息经服务器中转与存储。
Web 版**只提供网络服务器聊天**，不实现局域网 P2P 协议，也不与
Windows / Android 端互通。

```
浏览器A(账号甲) ─┐
浏览器B(账号乙) ─┼─ Web服务(Node, HTTP+WS) ─ 服务器统一存储账号/会话/文件
浏览器C(账号丙) ─┘
```

## 运行

使用者**只需要浏览器**，不需要安装任何东西、不需要命令行：

- **启动服务器**：在服务器机器上双击 `web\start-server.bat`（需装过 Node.js ≥ 18）。
  服务器启动后会自动打开聊天页面，并在窗口里列出局域网内的访问地址。
- **其他用户**：在浏览器地址栏输入窗口里显示的地址（例如 `http://192.168.1.10:8090`）
  即可使用。

开发者等价命令：`node web\server\main.js --http-host 0.0.0.0 --open`。

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--http` | 8090 | Web 界面端口（所有用户共用） |
| `--http-host` | 127.0.0.1 | 界面绑定地址；部署给他人访问用 `0.0.0.0`（`start-server.bat` 已默认） |
| `--data` | `web/data` | 数据目录（账号、聊天记录、共享文件） |
| `--open` | 关 | 启动后自动用默认浏览器打开页面 |

首次打开界面会要求**创建第一个账号**；之后**任何人都可以在登录页点「注册新账号」
直接注册**（注册后自动登录），已登录用户也可以在「账号与设置 → ＋新建账号」里
添加账号（不打断当前登录）。登录基于用户名 + 密码（scrypt 哈希存储，HttpOnly
会话 Cookie），登录与注册接口都按来源 IP 限速。服务器重启后会话失效，需要
重新登录。

## 一台机器多个账号

同一台机器（同一个浏览器）可以注册并使用任意多个账号：

- **注册只追加、不打扰当前会话**：在「账号与设置 → ＋新建账号」里创建新账号
  后，当前登录不变；首次初始化服务器时创建的第一个账号仍直接进入。
- **账号列表一键切换**：本浏览器登录过的账号都保存在「账号与设置」的账号
  列表里，点「切换」立即换号（无需重新输密码），点「移除」把该账号从本
  浏览器移除并注销其会话。
- **实现说明**：切换通过令牌完成——当前账号仍是 HttpOnly Cookie 会话，
  被切换到的账号在后续请求（含 WebSocket 与文件下载）里携带令牌；
  令牌保存在浏览器 localStorage，只对本机本浏览器有效。
- 同一浏览器同一时刻只有一个「当前」账号在线（多开请用浏览器的多用户
  配置文件或无痕窗口）。

## 功能范围

- **账号**：服务器上的所有账号互相可见（在线状态），点击用户即可发起聊天，
  无需添加 IP / 端口。
- **直聊**：任意两个账号间的一对一聊天，历史记录保存在服务器，换浏览器 /
  重装登录后仍在；已读回执（打开会话即回执）、正在输入、编辑、删除、
  表情回应、置顶、删除会话（双方历史同时移除）。
- **群组**：任意账号建群并勾选成员；群主可改名、发公告、邀请、移出成员；
  群主退出即解散群组；成员可随时退出；群已读回执（已读 n/m）。
- **文件**：浏览器上传到服务器（上限 512 MB），会话内所有成员直接从服务器
  下载 / 内联预览图片。

## 安全说明

- **界面有登录但传输仍是明文 HTTP**：仅在可信局域网内开放 `0.0.0.0`；跨公网
  请自行套 HTTPS 反向代理（WS 走 `wss` 即可，无需改代码）。
- 聊天正文以 `enc1:`（AES-256-GCM）加密落盘，内容密钥在数据目录
  `secret_key.json`；账号密码仅存 scrypt 哈希；登录与注册接口按来源 IP 限速
  （注册为开放注册：5 分钟内同一 IP 最多 20 次）。
- 文件下载接口要求登录会话；上传/下载路径对 fileId / 文件名做净化，
  防目录穿越。

上传下载与鉴权、服务器重启后的会话/群组/聊天历史持久化、群解散语义。
