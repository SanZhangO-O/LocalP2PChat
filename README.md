# LocalP2PChat

局域网 P2P 聊天工具(无需服务器,直连/组网通信,支持加密传输、文件与音视频通话)。

## 目录结构

```
├── android/   # Android 版（Kotlin + Compose）
└── windows/   # Windows 版（PyQt6，已实现）
```

## Android 版

- Android 客户端源码位于 `android/`,基于 Gradle + Kotlin 构建。
- 群组管理(群主权能):群主可修改群名称与群公告(新包 `group_update{groupId, groupName?, announcement?}`),成员端落库持久化并在群大厅顶部显示公告横幅;群主可将成员移出群组(新包 `kick_member{groupId, targetId}`,定向投递给被移出者并在群内广播),被移出者立即清理该群全部连接、从群列表移除(本地聊天记录保留)并收到提示,其他成员把该成员从成员列表移除。两条传播路径(群主中继 + 成员间 mesh)都会处理,且只有群主(`senderId` == 群信息中的 `creatorId`)能发起,非群主发起的管理包一律忽略并断开。群主改名不影响数字入群 ID(创建时冻结并持久化),成员重进群、重连后群名/公告仍然生效。
- 功能:局域网成员发现、直接聊天、群组网状聊天(主机离线也可用)、离线历史、文件传输、视频/语音通话。成员列表与直聊页均可发起视频或语音通话;`call_offer.media` 为 `"audio"` 时双方都不采集视频,纯语音通话界面(头像占位、静音/挂断)。每次通话结束都会在本地写入一条通话记录(去电/来电、接通/未接/被拒/取消/未接通、时长、是否视频),并在对应直聊会话中以系统样式行穿插显示(如「未接来电 14:32」),点击可直接回拨;未接来电在 Android 端还会发一条可点击跳转到该会话的通知。通话记录为纯本地数据(每会话保留最近 200 条),不进入聊天协议、不做端到端同步。聊天(群组+直连)、通话信令与媒体均全程 ECDH 握手加密;例外是文件字节流,采用 per-file 随机对称密钥的 AES-256-GCM 加密,该密钥本身经 ECDH 加密消息通道分发(下载握手行为 `file_download` 请求行含 uuid fileId 与可选下载 token=Base64(HMAC-SHA256(fileKey, "lc-file-dl-v1:"+fileId)),发送方恒时校验:token 存在但错误即拒绝,缺省(旧对端)才放行)。聊天与通话线路在同一连接内记录已见 nonce,发现重放即断开;加密包内附加逐方向严格递增的 `seq`(接收端要求恰好加一,拒绝重放/乱序/注入),对旧版本(不携带 `seq` 的)对端仍兼容:其报文持续放行,直到对端首次携带 `seq` 后才强制校验。消息删除采用墓碑收敛:在线成员即时删除,离线成员重连后经 `join_ack`/`history_reply` 的 `deletedIds` 补齐(每群上限 200 条,单包上限同值)。注意:无密码群组的加密仅防被动嗅探、不防主动中间人,建议创建群组时设置密码;首次添加联系人时建议在两端核对安全码(指纹),防止首次接触被中间人;删除消息的授权以"持有群组口令的成员"为界(墓碑不携带作者校验),口令泄露即等于成员可让全群删除任意消息。
- 双模拟器 / 真机端到端调试脚本见 `android/tools/emulator_e2e.py`。

## Windows 版

- 完整 Windows 桌面版位于 `windows/`，基于 PyQt6，功能与 Android 端互通。
- 群组管理与 Android 端同协议:`group_update`(群主改名/公告)、`kick_member`(群主移出成员);群大厅显示公告横幅,群主有「群设置」入口与成员行「移出」按钮。
- 通话同样支持视频/语音两种类型与本地通话记录：群成员列表与直聊页均有「通话」「语音」入口；会话内的通话记录系统行可点击回拨（语音记录回拨语音、视频记录回拨视频）。存储表见 `windows/localchat/storage.py` 的 `call_logs`。

## 版本兼容说明

- 通话功能要求 **两端（Android 与 Windows）均为最新版本**：媒体通道建立时需完成 `call_media_hello` 校验，旧版本客户端无法与本版本通话（表现为"对方未接听/媒体通道校验失败"）；聊天、文件传输与群组功能不受影响。升级后如通话异常，请确认对方也已升级。
- 群组管理（改名、公告、移出成员）要求 **两端均为包含该功能的版本**：旧版本对端不认识这两个包会直接忽略（聊天、文件、入群不受影响，只是管理动作不生效）。升级后如群管理不生效，请确认对方也已升级。
- `call_offer` 新增可选字段 `media`（`"audio"`/省略=`"video"`）。旧版本对端会忽略该字段并按视频处理，而视频帧仍受 `call_media_hello` 版本校验约束，因此新旧混合仍无法通话（与上述规则一致）。通话记录为本地数据，任何版本组合都不影响其写入与显示。

## 构建

### Windows 版

```bat
cd windows
pip install -r requirements.txt
python main.py
```

### Android 版

用 Android Studio 打开 `android/` 目录构建安装，或：

```bat
cd android
gradlew assembleDebug
```
